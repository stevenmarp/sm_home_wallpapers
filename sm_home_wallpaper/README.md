# Home Screen Wallpaper

Customize your Odoo home screen with beautiful random background wallpapers.
Upload multiple images and a random one is displayed each time you visit the
home screen.

## Features

- Upload multiple wallpaper images from Settings
- Random wallpaper displayed on each home screen visit
- Full-screen cover background, responsive on all devices
- Works with JPG, PNG, WebP and any image format
- Zero external dependencies
- Community & Enterprise compatible

## Installation

Install from the Odoo Apps store or copy the module folder to your addons path.

## Configuration

After installation, go to **Settings → General Settings → Home Screen Wallpaper**
and upload your background images.
